Store Mode

storefront What is Store Mode? expand_more
@if (openSection() === 'store-what') {

Store Mode turns your profile into a public storefront. When enabled, visitors see a dedicated Shop tab with all your active listings, your store description, policies, and a location map. A "Store" badge appears on your profile card in search and home grids so buyers can identify sellers at a glance.

}
toggle_on How to Enable Store Mode expand_more
@if (openSection() === 'store-enable') {

Go to Profile → Settings → Store and toggle Store Mode on. You can also add a store description, return policies, and a location so buyers know where you're based. Don't forget to tap Save when you're done.

}
add_shopping_cart Listing Items for Sale expand_more
@if (openSection() === 'store-list') {

Long-press any shoe in your Closet tab and tap Add Size Listing. Set the size, condition, asking price, and quantity, then tap Publish Listing. You can create multiple listings for the same shoe at different sizes — they'll be grouped together on your store page. To list a post item, long-press a post and tap List for Sale.

}
edit_note Managing Listings expand_more
@if (openSection() === 'store-manage') {

Go to your Profile → Store tab to see all your active listings grouped by shoe. Tap any size row to open the management sheet where you can change the status (Available / Pending / Sold), edit the details, or delete the listing entirely.

}
shopping_bag Buying from a Store expand_more
@if (openSection() === 'store-buy') {

Find a seller via Search or your home feed. Visit their profile and open the Shop tab. Tap a listing to see full details — size, condition, price, and quantity. Tap Message to Buy to open a pre-filled direct message asking about that specific item. All transactions are arranged privately between buyer and seller.

}

Social & Messaging

@if (openSection() === 'dm') {

Open the Messages tab to start or continue a conversation. Tap any user's avatar across the app to visit their profile, then tap the message icon to open a DM thread. Messages support text and photo sharing.

notifications Notifications & Push Alerts expand_more
@if (openSection() === 'notifications') {

Vault23 sends push notifications to your iPhone for messages, comments, likes, and new followers. Make sure notifications are enabled in iOS Settings → Vault23. You can review all past notifications in the bell icon on the home screen.

}
